# PreventWise Frontend

Welcome to the official repository for the PreventWise frontend! This is a modern, responsive web application built with Angular, designed to provide users with early risk assessment for non-communicable diseases (NCDs) like diabetes, heart disease, and stroke.

## ✨ Features

- **User Authentication**: Secure sign-up and login functionality for personalized experiences.
- **User Profile**: A dedicated profile page where users can view their prediction history.
- **AI-Powered Predictions**:
  - Diabetes Prediction
  - Heart Disease Prediction
  - Stroke Prediction
- **Dynamic UI**: A responsive and intuitive user interface built with Tailwind CSS.
- **Toast Notifications**: User-friendly feedback for actions like login and sign-up, powered by `ngx-toastr`.
- **Progressive Web App (PWA)**: Installable on mobile and desktop devices for an app-like experience.

## 🚀 Technologies Used

- **Framework**: [Angular](https://angular.io/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Programming Language**: [TypeScript](https://www.typescriptlang.org/)
- **Notifications**: [ngx-toastr](https://github.com/scttcper/ngx-toastr)
- **PWA Support**: [@angular/service-worker](https://angular.io/guide/service-worker-intro)

## 📦 Installation

To get a local copy up and running, follow these simple steps.

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/charlesntwari/preventWise-frontend.git
    ```
2.  **Navigate to the project directory:**
    ```sh
    cd preventWise-frontend
    ```
3.  **Install NPM packages:**
    ```sh
    npm install
    ```

## 🛠️ Usage

### Build

Run `ng build` to build the project. The build artifacts will be stored in the `dist/` directory. Use the `--prod` flag for a production build.

```sh
ng build --prod
```
